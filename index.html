BUG REPORT · UAT · INTEGRATION HIGH

Transfer receipt fails to post after a job uses stock

Cloud ERP (Business Central) · integration platform · mobile app
STEPS
  1. User completes a job in the mobile app and records a part used
  2. Integration creates a transfer order in the ERP
  3. Transfer receipt step runs
EXPECTED
Receipt posts, stock lands in the destination warehouse
ACTUAL
Receipt fails: the transfer order ID is not passed to the next step
ALSO FOUND  The transfer order only triggers when a used item is on the job.
Developer confirmed the integration bug and fixed it.
